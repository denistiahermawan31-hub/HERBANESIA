# HERBANESIA
### Discover, Learn, and Explore Indonesian Herbal Plants

HERBANESIA is a mobile application developed using Flutter to introduce Indonesia's diverse herbal plants and provide educational information about their traditional uses, potential benefits, and various herbal preparations.

The application helps users discover herbal plants, explore their potential uses, and learn how to prepare traditional herbal products through accessible information and step-by-step guides.

## Features

- **Herbal Plant Catalog** — Explore various Indonesian herbal plants along with their descriptions and characteristics.
- **Herbal Benefits** — Discover information about the traditional uses and potential benefits of herbal plants.
- **Herbal Preparation Ideas** — Learn about different herbal products that can be made from various plants.
- **Tools and Ingredients** — Find out what tools and ingredients are needed for each preparation.
- **Preparation Guide** — Follow step-by-step instructions for making traditional herbal preparations.

## Tech Stack

- Flutter
- Dart

## Getting Started

Clone this repository:

```bash
git clone https://github.com/denistiahermawan31-hub/herbanesia.git
```

Navigate to the project directory:

```bash
cd herbanesia
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
